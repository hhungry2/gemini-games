『ぽかぽかドット動物園 (Pixel Zoo Sanctuary)』 開発仕様書

プログラム描画ピクセルアートによる癒やしのブラウザ＆スマートフォン対応動物園ゲーム

1. ゲーム概要・企画コンセプト

コンセプト：「かわいい動物たちを眺めて、触れ合って、心がふんわり癒やされるドット絵動物園」
外部画像アセットに依存せず、すべての動物・植物・施設をプログラム内のカラーパレットとドットマトリクス（Canvas 2D）で描画します。

項目 仕様内容
対象プラットフォーム PC / スマホ / タブレットのモダンブラウザ（Chrome, Safari, Edge, Firefox等）
描画エンジン HTML5 Canvas 2D Context（image-rendering: pixelated によるピクセルアート拡大）
サウンドエンジン Web Audio API によるローファイ・オルゴール音＆環境音シンセ（外部mp3不要）
主なゲームプレイ 触れ合い（なでなで）、エサやり、おもちゃ遊び、温泉観察、放置ハート収集、仲間・施設解放

2. 動物キャラクター設計＆プログラム描画仕様

各動物は16×16ピクセルの厳密な1文字1ピクセル形式で定義されています。実行時に拡大スケーリングを行い、歩行・睡眠・リアクション等のアニメーションを合成します。

動物 特徴・アニメーション 固有アクション

🦫 カピバラ のんびりした表情。頭にゆずを乗せる。 温泉に入って目を細めて湯気を出す。

3. ゲームシステム＆コア・ゲームループ

  • なでなで：動物をタップ・撫でるとハートがポロロンと湧き出てご機嫌になります。
  • エサやり：地面をタップして美味しいごはんを投げると、近くの動物が集まってモグモグ食べます。
  • ボール遊び：ボールを転がすと動物たちが追いかけて遊びます。
  • 温泉＆昼夜サイクル：カピバラ温泉や桜の木を設置でき、時間帯（昼・夕・夜・雨）に応じて動物たちが眠ったり活発に行動します。

4. 操作系＆スマホ・フルスクリーン最適化仕様

スワイプでのパークスクロール、ピンチズーム、タップ操作に対応。フルスクリーン時はビューポート限界までダイナミックに拡大表示されます（AGENTS.md ルール1遵守）。
