# Games Hub 🕹️

ブラウザを開くだけで即座に遊べる、モダンで洗練された **Web ゲームコレクション** です。
登録不要・API キー不要で、PCキーボードおよびスマートフォン（タッチ操作）の両方に完全対応しています。

## 🎮 操作方法

### 🎯 アングリーバード (Angry Birds)
- **スリングショット引っ張り & 発射**: パチンコ台上の鳥をマウスクリック/タッチして後ろへ引っ張り、指・マウスを離して射出
- **特殊スキル発動**: 飛行中に画面をクリック/タップ
  - 🔴 **レッド**: 前方への気合い衝撃波（ブロック吹き飛ばし）
  - 🟡 **チャック**: 超高速ロケットダッシュ（木材特攻）
  - 🔵 **ブルー**: 3羽への拡散分裂（氷・ガラス特攻）
  - ⚫ **ボム**: 周囲を巻き込むTNT級大爆発（石砦粉砕）
  - 🔴 **テレンス**: 圧倒的質量によるゴリ押し粉砕（巨大バード）
- **ステージセレクト / リスタート**: 画面上部ボタンからいつでも選択・リトライ可能

### 🧱 ブロック崩し (Breakout)
- **パドル移動**: マウス移動 / `←` `→` / `A` `D` (スマホ: 画面下部ドラッグ または ◀ / ▶ ボタン)
- **ボール発射 / レーザー射撃**: `Space` / クリック / スマホ発射ボタン
- **アイテム**: 🔥ファイアボール (貫通) / 🧲マグネット (再発射) / ⚡レーザー / 🛡️バリア / 3x分裂 / ⇔拡大 / ▼スロー / ❤️1UP
- **ステージ**: 全5ステージ (Stage 5 巨大ボス戦)
- **ポーズ / 再開**: `P` / `Esc`

### 🔢 2048 (Classic 2048)
- **タイル移動**: 矢印キー (`↑` `↓` `←` `→`) / `WASD` / スマホスワイプ・D-Pad
- **1手戻す (Undo)**: `Ctrl + Z` / 「Undo」ボタン (最大10手まで巻き戻し可能)
- **💣 ボム**: 盤面上の最小タイルを1つ爆破消去
- **🔄 シャッフル**: 盤面のタイル位置をランダム再配置
- **⚡ 2倍化**: 最小タイルを2倍に昇格
- **サイズ切替**: 3x3 (Hard) / 4x4 (Classic) / 5x5 (Big)
- **リスタート**: `R` / リセットボタン

### 🟡 ドットイーター (Dot Eater)
- **移動**: 矢印キー (`↑` `↓` `←` `→`) / `WASD` / スマホスワイプ・十字キー
- **パワードット**: 大きなドットを食べると一定時間ゴーストを捕食可能
- **ポーズ / 再開**: `P` / `Esc`

### 🏓 ポン (Pong)
- **1P パドル (左)**: `W` / `S` または マウス移動 (スマホ: 画面左側ドラッグ)
- **2P パドル (右)**: `↑` / `↓` (スマホ: 画面右側ドラッグ)
- **モード**: VS CPU (Easy/Normal/Hard) / 2人対戦 / 壁打ちラリー

### 🚀 Star Striker (スター・ストライカー)
- **自機移動**: 矢印キー / `WASD` / マウス追従 (スマホ: 画面直接ドラッグ)
- **ショット**: `Space` / `Z` / 左クリック (自動連射AUTOトグルあり)
- **ハイパーボム**: `X` / `K` / 右クリック (スマホ: 💣 BOMB ボタン)
- **低速・精密移動 (フォーカス)**: `Shift` / `C`
- **ポーズ / 再開**: `P` / `Esc`

### 🍄 Gemini 3.7 Bros.
- **移動**: `←` / `→` または `A` / `D`
- **ジャンプ**: `Space` / `W` / `↑`
- **ダッシュ / 思考ビーム**: `Shift` / `J`

### 🕹️ テトリス (Tetris)
- **左右移動**: `←` / `→` (スマホ: ◀ / ▶)
- **回転**: `↑` または `X` (スマホ: ROTATE)
- **ソフトドロップ**: `↓` (スマホ: ▼)
- **ハードドロップ**: `Space` (スマホ: DROP)
- **ホールド**: `C` または `Shift` (スマホ: HOLD)
- **ポーズ / 再開**: `P`
- **リスタート**: `R`

### 💣 マインスイーパー (Minesweeper)
- **マスを開く**: 左クリック (スマホ: 掘るモードでタップ)
- **旗（フラグ）を立てる / 解除**: 右クリック (スマホ: 旗立てモードでタップ)
- **一括オープン (Chording)**: 開いている数字マスをクリック
- **リセット**: 上部中央のステータス顔ボタンをクリック

## 🚀 ローカル起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで `http://localhost:5173` を開いてプレイできます。
