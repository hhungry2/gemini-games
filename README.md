# Games Hub 🕹️

ブラウザを開くだけで即座に遊べる、モダンで洗練された **Web ゲームコレクション** です。
登録不要・API キー不要で、PCキーボードおよびスマートフォン（タッチ操作）の両方に完全対応しています。

---

## 🌟 収録ゲーム一覧

| ゲーム名 | ジャンル | 特徴 |
| :--- | :--- | :--- |
| **🕹️ テトリス (Tetris Neon)** | パズル・アクション | ネオングローが輝く本格テトリス。HOLD・NEXT・ゴースト表示・壁蹴り回転・Web Audioシンセ効果音・スマホタッチ操作対応。 |
| **💣 マインスイーパー (Minesweeper Cyber)** | 知略パズル | サイバーパンク調のクールなマインスイーパー。初手安全保証・自動連鎖オープン・Chording一括開封・初級〜上級・ベストタイム記録対応。 |

## 🎮 操作方法

### 🕹️ テトリス (Tetris Neon)
- **左右移動**: `←` / `→` (スマホ: ◀ / ▶)
- **回転**: `↑` または `X` (スマホ: ROTATE)
- **ソフトドロップ**: `↓` (スマホ: ▼)
- **ハードドロップ**: `Space` (スマホ: DROP)
- **ホールド**: `C` または `Shift` (スマホ: HOLD)
- **ポーズ / 再開**: `P`
- **リスタート**: `R`

### 💣 マインスイーパー (Minesweeper Cyber)
- **マスを開く**: 左クリック (スマホ: 掘るモードでタップ)
- **旗（フラグ）を立てる / 解除**: 右クリック (スマホ: 旗立てモードでタップ)
- **一括オープン (Chording)**: 開いている数字マスをクリック（周囲の旗数が一致している場合に残りを自動オープン）
- **リセット**: 上部中央のステータス顔ボタンをクリック

## 🚀 ローカル起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで `http://localhost:5173` を開いてプレイできます。
