# Tetris Neon 🕹️

ブラウザを開くだけで即座に遊べる、モダンなサイバーパンク・ネオン調の **Web テトリス** です。
API キーや会員登録は一切不要で、PCキーボードおよびスマートフォン（タッチコントローラー）の両方に完全対応しています。

---

## 🌟 特徴

- **本格的なテトリスシステム**:
  - 7種類のテトロミノ（I, J, L, O, S, T, Z）と 7-bag ランダマイザー
  - **HOLD（キープ）機能** ＆ **NEXT（次ミノ）プレビュー**
  - **ゴーストブロック表示**（着地予測ガイド）
  - ハードドロップ（Space）＆ ソフトドロップ（↓）
  - 壁蹴り（ウォールキック）対応の回転システム
  - スコア、レベル、消去ライン数、ハイスコア保存（LocalStorage）
  - 4列一括消去（TETRIS）時の特別エフェクト
- **レトロシンセ効果音**:
  - Web Audio API を活用した外部ファイル不要のシンセSE（移動、回転、ドロップ、ライン消去、ゲームオーバー）
  - サウンドのワンクリックON/OFF切り替え
- **マルチデバイス対応**:
  - PC: フルキーボード操作
  - スマホ・タブレット: 直感的な画面タッチコントローラー

---

## 🎮 操作方法

| アクション | PC キーボード | スマホ / タッチ |
| :--- | :--- | :--- |
| **左右移動** | `←` / `→` | ◀ / ▶ ボタン |
| **回転** | `↑` または `X` | ROTATE ボタン |
| **ソフトドロップ** | `↓` | ▼ ボタン |
| **ハードドロップ** | `Space` | DROP ボタン |
| **ホールド** | `C` または `Shift` | HOLD ボタン |
| **一時停止 / 再開** | `P` | - |
| **リスタート** | `R` (ゲームオーバー時) | もう一度プレイボタン |

## 🚀 ローカル起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

起動後、ブラウザで `http://localhost:5173` にアクセスしてください。

## 🌐 GitHub Pages へのデプロイ

本リポジトリには GitHub Actions による自動デプロイ設定が含まれています。

1. GitHub 上のリポジトリにコードを push します。
2. GitHub リポジトリの **Settings** > **Pages** で **Source** を **`GitHub Actions`** に設定します。
3. `main` ブランチに push されるたびに、自動的にビルド＆公開されます。
